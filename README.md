# Advanced Programming

## 📘 Overview
This repository contains materials, code examples, and exercises related to the Advanced Programming course at FCSE (FINKI)
– Ss. Cyril and Methodius University in Skopje.

It serves as a place to organize and share my progress, solutions, and examples created throughout the semester.

## 🧪 Structure of the Repository
```
AdvancedProgramming/src
│
├── Auditory_Exercises/         # Auditory (class) exercises and examples
├── Book/                       # Reference materials or book-related code
├── Exam/                       # Exam preparation tasks and problems
├── Exercises/                  # Auditory exercises solved using my own approach
├── Lab/                        # Laboratory exercises
├── utils/                      # utility files/classes
└── README.md                   # Repository overview

```

## 🚀 How to Use
1. Clone the repository:
    ```
   git clone https://github.com/ardit203/Advanced-Programming.git
   ```
2. Open the project in your preferred IDE (IntelliJ IDEA, Eclipse, etc.).
3. Explore the folders to find code samples, labs, or project files.
4. Run the programs and modify them freely for practice or experimentation.
