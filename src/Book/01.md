# Chapter 1 - OOP in Java

Object-oriented programming, or OOP for short, is the dominant programming paradigm that has replaced structured or procedural programming techniques developed in the 1970s.

An object-oriented program is represented through objects that communicate with each other by sending messages.
Each object has a specific functionality that is exposed to users, while its implementation is hidden. Many objects used within programs are already defined in certain libraries and are used according to their existing definitions and implementations.

Objects that are not yet defined or implemented must be created and implemented by the user. Whether the user creates their own object or reuses one from an existing library depends on several factors, such as available time or budget.
However, as long as an object meets the user’s specifications, it does not matter who implements it or how its functionality is realized.

## 1.1 Classes and Objects

Within this chapter, a solution to a simple object-oriented programming problem is presented.
The basic concepts for creating a class, defining its members (attributes and methods), and the process of instantiating objects from the corresponding class are explained.
The fundamental principles of encapsulation and interaction are also described.

> ### Problem 1.1
> Write a class that stores an array of integers.
> The class should be **immutable**. This means that once it is instantiated, the state of the object cannot be changed — in other words, the data stored in the object cannot be modified — and it **cannot be inherited** (it must be declared as `final`).
>
> For this class, named IntegerArray, the following methods should be implemented:
> 1. `IntegerArray(int a[])` – constructor that takes an array of integers.
> 2. `length(): int` – method that returns the length of the array.
> 3. `getElementAt(int i): int` – returns the element at position i.
> You may assume that the index i will always have a value in the interval [0, length() - 1].
> 4. `sum(): int` – returns the sum of all elements in the array.
> 5. `average(): double` – returns the average value of the elements in the array.
> 6. `getSorted(): IntegerArray` – returns a new object of the same class that contains the same values as the current object, but sorted in ascending order.
> 7. `concat(IntegerArray ia): IntegerArray` – returns a new object of the same class that contains all elements of the current object (this), followed by all elements of the ia object, preserving their order.
> 8. `toString(): String` – returns a textual representation of the object, where the elements are separated by commas and one space after each comma, and the entire string is enclosed in square brackets. Example: for an array containing the numbers 2, 1, and 4, the method should return "[2, 1, 4]".
>
> **Note**: All methods must be `public`.
>
> In addition to the IntegerArray class, you must write another class used to read an array of integers from an input data stream.
> This class should be called ArrayReader and should implement one public static method:
> - `readIntegerArray(InputStream input): IntegerArray` – reads an array of integers from the given input stream.
> The format is as follows:
>   - The first line contains a single integer indicating how many elements the array has.
>   - The next line contains the array elements separated by one or more spaces.

```java
import java.io.ByteArrayInputStream;
import java.io.IOException;
import java.io.InputStream;
import java.util.Arrays;
import java.util.Random;
import java.util.Scanner;

class IntegerArray {

    private int a[];

    public IntegerArray(int a[]) {
        this.a = Arrays.copyOf(a, a.length);
    }

    private IntegerArray(int a[], boolean to_copy) {
        if (to_copy)
            this.a = a;
        else
            this.a = Arrays.copyOf(a, a.length);
    }

    public int length() {
        return a.length;
    }

    public int getElementAt(int i) {
        return a[i];
    }

    public int sum() {
        int sum = 0;
        for (int e : a) sum += e;
        return sum;
    }

    public double average() {
        return sum() * 1.0 / length();
    }

    public IntegerArray getSorted() {
        int sorted_a[] = Arrays.copyOf(a, length());
        Arrays.sort(sorted_a);
        return new IntegerArray(sorted_a);
    }

    public IntegerArray concat(IntegerArray ia) {
        int res_a[] = new int[a.length + ia.a.length];
        System.arraycopy(a, 0, res_a, 0, a.length);
        System.arraycopy(ia.a, 0, res_a, a.length, ia.a.length);
        return new IntegerArray(res_a, true);
    }

    public String toString() {
        return Arrays.toString(a);
    }

    @Override
    public int hashCode() {
        final int prime = 31;
        int result = 1;
        result = prime * result + Arrays.hashCode(a);
        return result;
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj)
            return true;
        if (obj == null)
            return false;
        if (getClass() != obj.getClass())
            return false;
        IntegerArray other = (IntegerArray) obj;
        return Arrays.equals(a, other.a);
    }
}

class ArrayReader {

    public static IntegerArray readIntegerArray(InputStream input) {
        Scanner jin = new Scanner(input);
        int n = jin.nextInt();
        int a[] = new int[n];
        for (int i = 0; i < n; ++i) {
            a[i] = jin.nextInt();
        }
        jin.close();
        return new IntegerArray(a);
    }
}
```

First, the class `IntegerArray` is defined, which contains only one instance variable — an array of integers `a`.
To make the class `immutable`, it must be declared as `final`.

The class needs to define a constructor that takes a single argument — an array of integers whose contents will be copied into the array of integers stored as the instance variable.
For this purpose, the built-in method `Arrays.copyOf(...)` is used.

The methods `length()`, `getElementAt(i)`, `sum()`, and `average()` implement simple operations involving arrays of integers.

The method `IntegerArray getSorted()` should return a new object of the class `IntegerArray` in which the array of integers contains the same values as the array from the this object, but sorted.

It is important here to create a copy of the array stored in the this object, then sort the copy (using the built-in `Arrays.sort()` function), and pass it as an argument to the constructor when creating the new IntegerArray object.
A common mistake when solving this task is calling `Arrays.sort()` directly on the array stored in the this object, which would modify the array in both the this object and the resulting object.

In the `IntegerArray concat(IntegerArray ia)` method, it is necessary to return a new object containing an array obtained by merging the array from the this object with the array from the ia object.
To avoid modifying the array in the this object, you should first create a new integer array whose length is equal to the sum of the lengths of the two arrays.
Then, using the `System.arraycopy()` function, copy the contents of the array from the this object, followed by the contents of the array from the ia object.
The resulting array is then passed as an argument to the constructor when creating the new object.
The functionalities related to input and output data streams, which are required in the `ArrayReader` class, will be explained in more detail in the following chapters.

For tasks where inheritance and polymorphism are expected to be used, the most important first step is to identify the relationships between the data and to design the classes and their dependencies accordingly.

In this task, the definitions of the transaction classes are particularly important.
First, the class Transaction is defined as an abstract class, and from it, two other classes are derived for the concrete types of transactions.

Although the task statement does not explicitly require it, for the class Transaction to be abstract, it must define at least one abstract method.
Abstract methods are methods that have a definition (name and parameters) but no implementation.

In this case, that method would be the one returning the fee (provision) for a given transaction:
- `double getProvision();`

This method should then be properly overridden in the derived classes according to the requirements of the task.

In this way, through the use of polymorphism, all objects instantiated from the subclasses of Transaction will have different behaviors in accordance with their own implementation of the getProvision method.


```java
import java.util.*;

class Bank {
    private String name;
    private Account[] accounts;

    private double totalTransfers;
    private double totalProvision;

    public Bank(String name, Account[] accounts) {
        this.name = name;
        this.accounts = Arrays.copyOf(accounts, accounts.length);
        this.totalTransfers = 0.0;
        this.totalProvision = 0.0;
    }

    public boolean makeTransaction(Transaction transaction) {
        Optional<Account> from = findAccount(transaction.getFromId());
        Optional<Account> to = findAccount(transaction.getToId());
        if (from.isPresent() && to.isPresent()) {
            Account fromAccount = from.get();
            Account toAccount = to.get();
            double fromBalance = fromAccount.getBalance();
            double toBalance = toAccount.getBalance();
            double amount = transaction.getAmount();
            double provision = transaction.getProvision();
            if (provision + amount <= fromBalance) {
                if (fromAccount.getId() == toAccount.getId()) {
                    fromBalance = toBalance = (fromBalance - provision);
                } else {
                    fromBalance -= provision + amount;
                    toBalance += amount;
                }
                fromAccount.setBalance(fromBalance);
                toAccount.setBalance(toBalance);
                updateTotals(amount, provision);
                return true;
            }
        }
        return false;
    }

    void updateTotals(double amount, double provision) {
        this.totalTransfers += amount;
        this.totalProvision += provision;
    }

    Optional<Account> findAccount(long id) {
        return Arrays.stream(accounts)
                .filter(each -> each.getId() == id)
                .findAny();
    }

    public static String toString(long amount) {
        return String.format("%.2f$", amount / 100.);
    }

    @Override
    public String toString() {
        StringBuilder result = new StringBuilder();
        result.append("Name: ");
        result.append(name);
        result.append("\n\n");
        Arrays.stream(accounts)
                .forEach(each -> result.append(each.toString()));
        return result.toString();
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Bank bank = (Bank) o;
        return Objects.equals(name, bank.name) &&
                Arrays.equals(accounts, bank.accounts) &&
                Objects.equals(totalTransfers, bank.totalTransfers) &&
                Objects.equals(totalProvision, bank.totalProvision);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, accounts, totalTransfers, totalProvision);
    }

    public double totalProvision() {
        return totalProvision;
    }

    public double totalTransfers() {
        return totalTransfers;
    }

    public Account[] getAccounts() {
        return accounts;
    }
}

class FlatAmountProvisionTransaction extends Transaction {

    private final double flatAmount;

    public FlatAmountProvisionTransaction(long fromId, long toId,
                                          double amount, double flatAmount) {
        super(fromId, toId, amount, "FlatAmount");
        this.flatAmount = flatAmount;
    }

    @Override
    public double getProvision() {
        return flatAmount;
    }

    public double getFlatAmount() {
        return flatAmount;
    }
}

class FlatPercentProvisionTransaction extends Transaction {
    private final int percent;

    public FlatPercentProvisionTransaction(long fromId, long toId,
                                           double amount, int percent) {
        super(fromId, toId, amount, "FlatPercent");
        this.percent = percent;
    }

    @Override
    public double getProvision() {
        long amount = (long) this.amount / 100;
        return percent * amount;
    }

    public int getPercent() {
        return percent;
    }
}

abstract class Transaction {
    final long fromId;
    final long toId;
    final double amount;
    final String description;

    public Transaction(long fromId, long toId, double amount, String description) {
        this.fromId = fromId;
        this.toId = toId;
        this.amount = amount;
        this.description = description;
    }

    public long getFromId() {
        return fromId;
    }

    public long getToId() {
        return toId;
    }

    public double getAmount() {
        return amount;
    }

    public abstract double getProvision();

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Transaction that = (Transaction) o;
        return Objects.equals(fromId, that.fromId) &&
                Objects.equals(toId, that.toId) &&
                Objects.equals(amount, that.amount) &&
                Objects.equals(description, that.description);
    }

    @Override
    public int hashCode() {
        return Objects.hash(fromId, toId, amount, description);
    }

    public String getDescription() {
        return description;
    }
}
```

The `makeTransaction(Transaction t)` method in the Bank class is the most complex to implement. In it, several validations need to be performed before the transaction itself is executed. Additionally, care should be taken not to make the method too long, as that would make it difficult to understand and test.

For this purpose, the first validation (whether the sender’s and recipient’s accounts exist) uses a private helper method `findAccount(long id)`. If both accounts are found, it is then checked whether the sender has enough funds to cover both the transaction amount and its fee. If that condition is satisfied, the transaction amount plus the fee are deducted from the sender’s account, and the transaction amount is added to the recipient’s account. The bank’s records are then updated accordingly using the method updateTotals(long amount, long provision).


> ### Problem 1.3
> Implement a class `Canvas` that stores different shapes.
> For each shape, store:
> - `id: String`
> - `color: Color` (an `enum` is provided)
>
> All shapes must implement two interfaces:
> - `Scalable` — defined with a single method v`oid scale(float scaleFactor)` for appropriately increasing/decreasing the size of the shape by the given factor.
> - `Stackable` — defined with a single method `float weight()` which returns the weight of the shape (computed as the area of the corresponding shape).
>
> In the Canvas class implement the following methods:
> - `void add(String id, Color color, float radius)` — to add a circle.
> - `void add(String id, Color color, float width, float height)` — to add a rectangle.
>   - When adding a new shape, it must be placed in the list of shapes at the appropriate position according to its weight. The elements must always be ordered by weight in descending order.
> - `void scale(String id, float scaleFactor)` — scales the shape with the given id by the given `scaleFactor`. If necessary, the shapes must be repositioned to preserve the required ordering of elements.
> You must not use sorting of the list.
> - `toString()` — returns a string composed of all figures in order. For each figure, append:
>   - `C: [id:%5s] [color:%10s] [weight:%10.2f]` if it is a circle
>   - `R: [id:%5s] [color:%10s] [weight:%10.2f]` if it is a rectangle

In this task there should be two types of shapes (circles and rectangles), where both shapes are scalable and their weight can be measured. The scalability of the shapes and the measurement of their weight is enabled through two interfaces, `Scalable` and `Stackable`, which both shapes must implement.

Since circles and rectangles share two common pieces of data (ID and color), a base class `Shape` is defined in which these fields are specified. The classes `Circle` and `Rectangle` accordingly inherit from `Shape`.

Because all shape types must implement the Scalable and Stackable interfaces, their implementation is declared directly in the `Shape` class. In this class, the methods will not be implemented, so the class becomes `abstract`.

The classes `Rectangle` and `Circle` inherit from `Shape` and implement the methods defined by the interfaces. In the `scale(float scaleFactor)` method, all dimensions of the shape are multiplied by `scaleFactor`, while in the `weight()` method the area of the shape is calculated according to the appropriate mathematical formula.

In the `Canvas` class, a list of shapes is stored (objects instantiated from the derived classes of `Shape`) which are referenced by a reference of type `Shape`.

This task also demonstrates the concept of method overloading, through the implementation of methods named add with different signatures.

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

enum Color {
    RED, GREEN, BLUE
}

interface Stackable {
    float weight();
}

interface Scalable {
    void scale(float scaleFactor);
}

abstract class Shape implements Scalable, Stackable {
    protected String id;
    protected Color color;

    public Shape(String id, Color color) {
        this.id = id;
        this.color = color;
    }
}

class Circle extends Shape {
    float r;

    public Circle(String id, Color color, float r) {
        super(id, color);
        this.r = r;
    }

    @Override
    public void scale(float scaleFactor) {
        r *= scaleFactor;
    }

    @Override
    public float weight() {
        return (float) (Math.PI * r * r);
    }

    @Override
    public String toString() {
        return String.format("C: %-5s%-10s%10.2f\n", id, color, weight());
    }
}

class Rectangle extends Shape {
    float width, height;

    public Rectangle(String id, Color color, float width, float height) {
        super(id, color);
        this.width = width;
        this.height = height;
    }

    @Override
    public void scale(float scaleFactor) {
        width *= scaleFactor;
        height *= scaleFactor;
    }

    @Override
    public float weight() {
        return width * height;
    }

    @Override
    public String toString() {
        return String.format("R: %-5s%-10s%10.2f\n", id, color, weight());
    }
}

class Canvas {
    List<Shape> shapes;

    public Canvas() {
        shapes = new ArrayList<>();
    }

    // find index to insert so list stays sorted by weight descending
    int find(float weight) {
        for (int i = 0; i < shapes.size(); ++i) {
            if (shapes.get(i).weight() < weight) {
                return i;
            }
        }
        return shapes.size();
    }

    public void add(String id, Color color, float radius) {
        Circle c = new Circle(id, color, radius);
        int index = find(c.weight());
        shapes.add(index, c);
    }

    public void add(String id, Color color, float width, float height) {
        Rectangle rect = new Rectangle(id, color, width, height);
        int index = find(rect.weight());
        shapes.add(index, rect);
    }

    public void scale(String id, float scaleFactor) {
        Shape s = null;
        for (int i = shapes.size() - 1; i >= 0; i--) {
            if (shapes.get(i).id.equals(id)) {
                s = shapes.get(i);
                shapes.remove(i);
                break;
            }
        }
        if (s == null) return; // no shape with that id; keep behavior safe
        s.scale(scaleFactor);
        int index = find(s.weight());
        shapes.add(index, s);
    }

    @Override
    public String toString() {
        StringBuilder sb = new StringBuilder();
        for (Shape shape : shapes) {
            sb.append(shape);
        }
        return sb.toString();
    }
}
```
