# Chapter 3 - Reading and Writing Data

In this chapter, the classes from the **java.util** package will be presented. These classes are intended for reading from an input data stream and writing to an output data stream. They are most commonly used for reading from the keyboard or an input file, and for writing to the screen or an output file. In the community, they are also known as **Input/Output (I/O) classes**.
The exercises demonstrate how to correctly use the classes designed for reading from an input data stream and how to properly format and send data to an output data stream.

## 3.1 Using the `Scanner` Class for Reading Data
The `Scanner` class is most commonly used for reading data from the keyboard 
and from text files.
By simply replacing the argument `System.in` (in the constructor of the 
`Scanner` class) with a suitable object representing a data stream connected
to a text file, it becomes possible to read from that text file.

`Scanner streamObject = new Scanner(new FileInputStream(fileName));`

The methods of the `Scanner` class allow reading from any input data stream (in this case, from the keyboard or a text file).

The `Scanner` class divides the input data into tokens using a separator (by default, a whitespace).
These tokens can then be converted into values of different types using its interface methods.

> ### Problem 3.1
> Implement a class `Subtitles` that reads a subtitle stream 
> (standard input, file, …) in standard .srt format. 
> Each subtitle entry consists of an index number, a start display time, 
> an end display time, and the text, in the following format (example):
>
> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;*2*
>
> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *00:00:48,321--> 00:00:50,837*
> 
> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *Let's see a real bet.*
> 
> The text block may span multiple lines. All entries are separated by a single blank line.
> Your task is to implement the methods:
> - `Subtitles()` — default constructor.
> - `int loadSubtitles(InputStream inputStream)` — reads the subtitles from the input stream and returns how many entries were read.
> - `void print()` — prints the loaded subtitles in the same format as they were read.
> - `void shift(int ms)` — shifts the start/end times of all subtitle entries by the given number of milliseconds (the value may be negative, which shifts times backward).

When solving tasks that require reading data from an input data stream, it is very important first to understand the **format of the input data**.
This format can be **structured** or **unstructured**.
The strategy and method of reading such data can vary:

* Reading the input data stream **line by line**
* Reading **character by character** (byte by byte)
* **Tokenizing** the input data stream directly if the format of the data is known
* Providing **direct conversion** of the data if the structure of the record is known in advance (for example, reading the values of a matrix, a well-defined data structure, etc.)

Once the format of the input data is understood, a decision can be made about which **classes and methods** from those classes will be used to read the data.

```java
import java.io.InputStream;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Subtitles {
    List<Element> elements;

    public Subtitles() {
        elements = new ArrayList<>();
    }

    public int loadSubtitles(InputStream inputStream) {
        Scanner scanner = new Scanner(inputStream);
        while (scanner.hasNextLine()) {
            String line = scanner.nextLine();
            int number = Integer.parseInt(line);
            String time = scanner.nextLine();

            StringBuilder text = new StringBuilder();
            while (true) {
                if (!scanner.hasNextLine()) break;
                line = scanner.nextLine();
                if (line.trim().length() == 0) break;
                text.append(line).append("\n");
            }

            Element element = new Element(number, time, text.toString());
            elements.add(element);
        }
        return elements.size();
    }

    public void shift(int ms) {
        for (Element e : elements) {
            e.shift(ms);
        }
    }

    public void find(String text) {
        for (Element e : elements) {
            if (e.findText(text)) {
                System.out.println(e.number);
            }
        }
    }

    public void print() {
        for (Element e : elements) {
            System.out.println(e);
        }
    }
}

class Element {
    public int timeFrom;
    public int timeTo;
    public String text;
    public int number;

    public Element(int number, String time, String text) {
        this.number = number;
        String[] parts = time.split("-->");
        timeFrom = stringToTime(parts[0].trim());
        timeTo = stringToTime(parts[1].trim());
        this.text = text;
    }

    public void shift(int ms) {
        timeFrom += ms;
        timeTo += ms;
    }

    public boolean findText(String someText) {
        return text.contains(someText);
    }

    static int stringToTime(String time) {
        String[] parts = time.split(",");
        int res = Integer.parseInt(parts[1]);
        parts = parts[0].split(":");
        int sec = Integer.parseInt(parts[2]);
        int min = Integer.parseInt(parts[1]);
        int h = Integer.parseInt(parts[0]);
        res += sec * 1000;
        res += min * 60 * 1000;
        res += h * 60 * 60 * 1000;
        return res;
    }

    static String timeToString(int time) {
        int h = time / (60 * 60 * 1000);
        time %= (60 * 60 * 1000);
        int m = time / (60 * 1000);
        time %= (60 * 1000);
        int s = time / 1000;
        int ms = time % 1000;
        return String.format("%02d:%02d:%02d,%03d", h, m, s, ms);
    }

    @Override
    public String toString() {
        return String.format("%d\n%s --> %s\n%s", number,
                timeToString(timeFrom), timeToString(timeTo), text);
    }
}

public class SubtitlesTest {
    public static void main(String[] args) {
        Subtitles subtitles = new Subtitles();
        int n = subtitles.loadSubtitles(System.in);

        System.out.println("+++++ ORIGINAL SUBTITLES +++++");
        subtitles.print();

        int shift = n * 37;
        shift = (shift % 2 == 1) ? -shift : shift;

        System.out.printf("SHIFT FOR %d ms%n", shift);
        subtitles.shift(shift);

        System.out.println("+++++ SHIFTED SUBTITLES +++++");
        subtitles.print();
    }
}
```

In this task, it’s easy to see that the data for a single subtitle entry are organized in at least three lines. 
The first line contains the sequential number, the second line contains the time interval during which the subtitle 
should be displayed, and the following line(s) contain the subtitle text. When reading line by line (as in this situation),
you can use the **`Scanner`** or **`BufferedReader`** classes. This task is solved using the **Scanner** class.

First, create a **`Scanner`** object by passing an **`InputStream`** object to the **`Scanner`** constructor.

Since the input must be read line by line, you should write a loop that runs as long as there are lines to read 
from the file. To check whether the end of the file has been reached, use `scanner.hasNextLine()`. 
Inside the loop, read one line and parse it as an integer (because that line represents the subtitle’s index).
Then read another line and store it as a string, which will later be transformed into two time intervals. Next, 
using a nested loop, read the lines that contain the subtitle text until you reach a blank line 
(subtitles are separated by a blank line). Each read line is appended to a `StringBuilder` 
to avoid creating new string objects repeatedly. As a result of the nested loop, you obtain the 
full subtitle text as a single string by calling `toString()` on the `StringBuilder`. 
For reading the input stream line by line, use the `nextLine()` method of the **`Scanner`** class.

Additionally, the entry that contains the start and end times of the subtitle needs to be processed. 
For that purpose, in the constructor of the **`Element`** class, 
split the line that contains the start and end times into two strings using the “arrow” separator (`-->`). 
The two resulting strings are then converted into milliseconds elapsed since the beginning of the movie.



### 3.1.1 Using the `PrintWriter` Class for Writing Data

The PrintWriter class is used for formatted printing of data to an output stream.

> ### Problem 3.2
> Implement a class `CheckIn` that reads, from an input stream (standard input, file, …), data about a user’s check-in/check-out.
> The data contain: Name (unique), start date and end date (format `dd.mm.YYYY`) with time (24-hour format) of check-in and check-out. All fields are separated by a single space.
The date and time are separated by a dash (`-`). In the date, day, month, and year may be separated by `.` or `/`; in the time, hours and minutes may be separated by `:` or `.`.
>
> &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;*John 03.06.2015-11:15 03/06/2015-20.45*
> 
> Methods to implement
>
> - `CheckIn()` — default constructor.
> - `void readTimes(InputStream inputStream`) — reads the data.
> - `void writeTimes(OutputStream outputStream)` — prints all check-in times sorted in ascending order by the user’s check-in time. When printing, the name is printed left-aligned in a field of 15 characters. The date is printed once in the format dd.mm.YYYY. Then follow the check-in and check-out times, and finally the total duration of presence in minutes.
> 
> The method `readTimes` throws an exception of type `InvalidCheckInTimes` if the check-in date and check-out date are different, or if the check-in time is after the check-out time. The exception’s `getMessage()` must return the input record that caused the exception. All check-ins and check-outs read before the moment an exception is thrown must remain recorded.


Similar to the previous task, in this one as well, reading the data is best done **line by line**, where each line contains information about the employees’ working hours.

First, an object of the **`Scanner`** class is created, and then, using a loop, lines are read one by one from the input stream. Each of the read text lines is split into three parts using a space as a separator. The first string contains the employee’s name, the second string contains the start of the shift, and the third string contains the end of the shift.

The second and third strings are further split using the **“-”** character as a separator. This results in two strings of length 2 — the first string being the date, and the second string being the time. Once the start and end dates and times are obtained, they need to be formatted. Since the day, month, and year in the dates can be separated by either “/” or “.”, and the program output requires them to be separated by “.”, the `replace` method from the **`String`** class is used to replace all “/” with “.”.

For parsing the time, the program first attempts to split the string using “:”. If this operation fails (does not return an array of size 2), the string is then split using “.” instead.

In this task, besides reading from the input stream, the results also need to be **written to an output stream** (the object of class `OutputStream`), using the `writeTimes` method. For that purpose, an object of the **`PrintWriter`** class is created, passing the `OutputStream` object to its constructor. The data about the shifts (objects of class `CheckInTime`) are then sorted and printed using the `println()` method from the **`PrintWriter`** class.

When working with **`PrintWriter`**, it is important to call the `flush()` method to ensure that the data accumulated in the `PrintWriter` buffer are actually written to the output stream. Finally, every open data stream must be closed by calling the `close()` method.

```java
import java.io.InputStream;
import java.io.OutputStream;
import java.io.PrintWriter;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Scanner;

class CheckIn {
    List<CheckInTime> elements;

    public CheckIn() {
        elements = new ArrayList<CheckInTime>();
    }

    public void loadTimes(InputStream inputStream) throws InvalidCheckInTimes {
        Scanner scanner = new Scanner(inputStream);
        while (scanner.hasNextLine()) {
            String line = scanner.nextLine();
            String[] parts = line.split(" ");
            String name = parts[0];
            String[] time1 = parts[1].split("-");
            String[] time2 = parts[2].split("-");

            CheckInTime time = new CheckInTime(
                name,
                CheckInTime.setDateFormat(time1[0]),
                CheckInTime.setDateFormat(time2[0]),
                CheckInTime.strToTime(time1[1]),
                CheckInTime.strToTime(time2[1])
            );

            if (!time.valid()) throw new InvalidCheckInTimes(line);
            elements.add(time);
        }
    }

    public void printTimes(OutputStream outputStream) {
        PrintWriter writer = new PrintWriter(outputStream);
        Collections.sort(elements);
        for (CheckInTime checkInTime : elements) {
            writer.println(checkInTime);
        }
        writer.flush();
        writer.close();
    }
}

class CheckInTime implements Comparable<CheckInTime> {
    private String name;
    private String dateFrom;
    private String dateTo;
    private int timeFrom;
    private int timeTo;

    public CheckInTime(String name, String dateFrom, String dateTo, int timeFrom, int timeTo) {
        this.name = name;
        this.dateFrom = dateFrom;
        this.dateTo = dateTo;
        this.timeFrom = timeFrom;
        this.timeTo = timeTo;
    }

    public boolean valid() {
        return dateFrom.equals(dateTo) && timeFrom <= timeTo;
    }

    public static int strToTime(String time) {
        String[] t = time.split(":");
        if (t.length == 1) {
            t = time.split("\\.");
        }
        return Integer.parseInt(t[0]) * 60 + Integer.parseInt(t[1]);
    }

    public static String setDateFormat(String date) {
        date = date.replace("/", ".");
        return date;
    }

    @Override
    public String toString() {
        return String.format(
            "%-15s%s %02d:%02d-%02d:%02d (%d)",
            name,
            dateFrom,
            timeFrom / 60, timeFrom % 60,
            timeTo / 60,   timeTo % 60,
            timeTo - timeFrom
        );
    }

    @Override
    public int compareTo(CheckInTime o) {
        return Integer.compare(timeFrom, o.timeFrom);
    }
}

class UnsupportedFormatException extends Exception {
    String data;

    public UnsupportedFormatException(String data) {
        this.data = data;
    }

    @Override
    public String getMessage() {
        return data;
    }
}

class InvalidCheckInTimes extends Exception {
    String data;

    public InvalidCheckInTimes(String data) {
        this.data = data;
    }

    @Override
    public String getMessage() {
        return data;
    }
}

public class CheckInTest {
    public static void main(String[] args) {
        CheckIn checkIns = new CheckIn();
        try {
            checkIns.loadTimes(System.in);
        } catch (InvalidCheckInTimes e2) {
            System.out.println("InvalidCheckInTimes: " + e2.getMessage());
        }
        System.out.println(String.format("====== PRINT CHECK INS ======"));
        checkIns.printTimes(System.out);
    }
}

```

## 3.2 Using the `BufferedReader` Class for Reading Data
The BufferedReader class can be used to read from an input data stream (including a text file).
An object of the `BufferedReader` class provides the methods `read()` and `readLine()`.
To use `BufferedReader` for reading from a text file, the following libraries need to be imported:

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.FileNotFoundException;
import java.io.IOException;
```
The `BufferedReader` class takes an object of the `FileReader` class as an argument in its constructor.
A data stream from `BufferedReader` is created and linked to the text file in the following way:

```java
BufferedReader readerObject;
readerObject = new BufferedReader(new FileReader(FileName));
```

After defining the `BufferedReader` object, the methods `read()` and `readLine()` can be used to read from the file with the name `FileName`.
The `readLine()` method works the same way as when reading from the keyboard, with the difference that here the data is read from a file.
The `read()` method reads a single character and returns a value (of type `int`) corresponding to the character read. Therefore, additional casting is often necessary:

```java
char next = (char)(readerObject.read());
```

Additionally, starting from Java 8, there is also the `lines()` method, which returns a `Stream<String> object` — representing a stream of text lines, where each string corresponds to one line of the data stream.

> ### Problem 3.3
> Define a class **`CakeShopApplication`** that stores information about all current cake and pie orders.
>
>For the class, define the following:
>
>* **`CakeShopApplication()`** — constructor.
>* **`int readCakeOrders(InputStream inputStream)`** — a method that reads information about multiple orders from an input data stream.
>  Each line contains information about one order in the following format:
>  `orderId item1Name item1Price item2Name item2Price ... itemNName itemNPrice`
>  where `orderId` is the ID of the order, followed by pairs of product names and their prices.
>  The method should return an integer representing the total number of products ordered across all successfully read orders.
>* **`void printLongestOrder(OutputStream outputStream)`** — a method that prints, to an output stream, the order with the largest number of ordered products, in the format:
>  `orderId totalOrderItems`,
>  where `totalOrderItems` is the total number of products ordered in that order.


From the task requirements, where it is clearly stated that the order information is given in separate lines, it can be concluded that reading from the input stream should be done **line by line**.

Although the task can also be solved using the **`Scanner`** class, here the approach using the **`BufferedReader`** class for reading from an input data stream will be demonstrated.

In the function `int readCakeOrders(InputStream inputStream)`, an object of type **BufferedReader** is first created. In the constructor of the **`BufferedReader`** class, an object of type **`InputStreamReader`** is passed, and in the constructor of **`InputStreamReader`**, an object of type **`InputStream`** is passed. This is a general solution that can work for reading from any kind of input stream (since the **`InputStream`** class has hundreds of subclasses).

Then, using a loop, lines are read one by one until the method `readLine()` from the **`BufferedReader`** class returns `null`. For each line read, the static method `createOrder` from the **`Order`** class is called, which parses all the information about the order and the items it contains.

The relevant data for a single order, written in one line of the input stream, are separated by spaces, where the **`0th position`** contains the **`order ID`**, and each **odd position (1, 3, etc.)** contains an **item name**, while each **even position (2, 4, etc.)** contains the **item price**. Accordingly, a list of all items is created and passed as an argument to the constructor of the **`Order`** class, together with the order ID found at the 0th position.

At the end of the reading process, the `close()` method is called to close the input data stream.

A commented-out alternative solution using the `lines()` method from the **`BufferedReader`** class is also provided.

```java
import java.io.*;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.stream.Collectors;

class Item {
    private String name;
    private int price;

    public Item(String name) {
        this.name = name;
        this.price = 0;
    }

    public void setPrice(int price) {
        this.price = price;
    }
}

class Order implements Comparable<Order> {
    private int id;
    private List<Item> items;

    public Order() {
        this.id = -1;
        items = new ArrayList<>();
    }

    public Order(int id, List<Item> items) {
        this.id = id;
        this.items = items;
    }

    public static Order createOrder(String line) {
        String[] parts = line.split("\\s+");
        int orderId = Integer.parseInt(parts[0]);
        List<Item> items = new ArrayList<>();

        Item item = null;
        for (int i = 1; i < parts.length; i++) {
            if (i % 2 == 1) { // item name is here
                item = new Item(parts[i]);
            } else {
                item.setPrice(Integer.parseInt(parts[i]));
                items.add(item);
            }
        }
        return new Order(orderId, items);
    }

    public List<Item> getItems() {
        return items;
    }

    public int getNumberOfItems() {
        return items.size();
    }

    @Override
    public int compareTo(Order o) {
        return Integer.compare(this.items.size(), o.items.size());
    }

    @Override
    public String toString() {
        return this.id + " " + this.items.size();
    }
}

class CakeShopApplication {
    private List<Order> orders;

    public CakeShopApplication() {
        this.orders = new ArrayList<>();
    }

    public int readCakeOrders(InputStream inputStream) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(inputStream));

        /* JAVA 8 Stream API solution
        this.orders = br.lines()
                .map(Order::createOrder)
                .collect(Collectors.toList());
        br.close();
        return this.orders.stream()
                .mapToInt(Order::getNumberOfItems)
                .sum();
        */

        String line;
        while ((line = br.readLine()) != null) {
            orders.add(Order.createOrder(line));
        }

        int sum = 0;
        for (Order order : orders) {
            sum += order.getNumberOfItems();
        }

        br.close();
        return sum;
    }

    public void printLongestOrder(OutputStream outputStream) {
        PrintWriter printWriter = new PrintWriter(outputStream);

        Order longestOrder = orders.get(0);

        /* JAVA 8 Stream API solution
        Order longestOrder = this.orders.stream()
                .max(Comparator.naturalOrder())
                .orElseGet(Order::new);
        */

        for (Order order : orders) {
            if (order.compareTo(longestOrder) > 0) {
                longestOrder = order;
            }
        }

        printWriter.println(longestOrder);
        printWriter.flush();
        printWriter.close();
    }
}

public class CakeShopApplicationTest1 {
    public static void main(String[] args) {
        CakeShopApplication cakeShopApplication = new CakeShopApplication();

        System.out.println("--- READING FROM INPUT STREAM ---");
        try {
            System.out.println(cakeShopApplication.readCakeOrders(System.in));
        } catch (IOException e) {
            e.printStackTrace();
        }

        System.out.println("--- PRINTING LARGEST ORDER TO OUTPUT STREAM ---");
        cakeShopApplication.printLongestOrder(System.out);
    }
}
```
